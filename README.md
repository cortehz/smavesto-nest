Portfolio API
Eine kompakte REST-API, entwickelt mit NestJS und Prisma. Das Projekt nutzt PostgreSQL als relationale Datenbank und setzt auf eine modulare Architektur sowie vollständige Typsicherheit, um eine performante und skalierbare Basis für Portfolio-Anwendungen zu bieten.

Tech Stack
Backend: NestJS (TypeScript)

ORM: Prisma

Datenbank: PostgreSQL
